# External Integrations

This document tracks external APIs, databases, and third-party services integrated into the project.

## Frontend Services

- **Google Fonts**: Integrated via `<link>` tags for typography (`Space Grotesk` and `Syne`).
- **Lucide Icons**: Used for SVG icon rendering via `https://unpkg.com/lucide@latest`. These are rendered directly in the client.

## Backend Services

- **None Detected**. The website operates purely on the client side without dynamic data fetching from external databases, CMS platforms, or authentication providers. The site is a static portfolio and landing page.

## Tools and Extensions

- **MCP / AI Extensions**: Configuration present via `cline_mcp_settings.json` which integrates with external AI agents and toolsets.
