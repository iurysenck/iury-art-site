# Project Structure

This document outlines the directory layout and file organization.

## Root Directory

- `index.html`: The main homepage file containing the primary site structure.
- `README.md`: Project documentation.
- `robots.txt` & `sitemap.xml`: SEO and search engine configuration files.
- `cline_mcp_settings.json`: MCP tool configuration settings for AI agents.

## Subdirectories

- `teste/`: Experimental, draft, or alternate landing pages.
  - `teste.html`: Sandbox or WIP landing page.
  - `landing-vhs-glitch.html`: Specific effect test page.
  - `portfolio-portfolio.html`: Draft portfolio design.
- `arte/`: Likely contains artistic assets, generative art, or specific project files.
- `imgs/`: Standard image assets directory for the website's graphical content.

## Conventions

- Flat structure for primary pages (currently just `index.html` at root).
- Experimental files are grouped in `teste/`.
- Styling is kept within the respective HTML files rather than in a separate `css/` folder.
