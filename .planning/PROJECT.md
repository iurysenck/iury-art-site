# [MARCA] iury.art

## What This Is
A super portfolio page with an interactive 3D gallery and fullscreen particle transitions triggered on page scroll, inspired by Apple and Awwwards-tier websites.

## Core Value
To provide a visually stunning, immersive showcase of the user's work that wows visitors through smooth scrollytelling and high-end 3D interactions.

## Context
The site is currently a vanilla HTML/CSS/JS page. To maintain simplicity and avoid complex build setups, the upgrade will "Stay Vanilla" by bringing in Three.js via script tags rather than rewriting in a framework like React/Next.js.

## Requirements

### Validated
- [Existing capability] Serve static portfolio content
- [Existing capability] Custom cursor and basic styling

### Active
- [ ] Implement Three.js for 3D graphics in a vanilla environment
- [ ] Create a 3D gallery
- [ ] Implement fullscreen particle transitions
- [ ] Tie particle transitions and 3D gallery to scroll position (Scrollytelling)

### Out of Scope
- [Exclusion] Full rewrite in React/Next.js — decided to stay vanilla for simplicity.
