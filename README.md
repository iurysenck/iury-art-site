# iury.art

Site pessoal e portfolio de Iury Senck - Fotógrafo & Produtor de Conteúdo Visual.

## 🌐 Acesse

**[iury.art](https://iury.art)**

## ✨ Features

- Design moderno estilo Awwwards
- Cursor personalizado interativo
- Animações suaves on scroll
- Efeito parallax no hero
- Grid de portfolio responsivo
- Formulário de contato funcional
- Totalmente responsivo

## 🛠️ Stack

- HTML5 semântico
- CSS3 com variáveis customizadas
- JavaScript Vanilla
- [Lucide Icons](https://lucide.dev)
- Google Fonts (Space Grotesk, Syne)

## 🚀 Deploy

O site foi atualizado manualmente via GitHub e será refletido no Vercel após sincronização automática.

### Integração com Vercel

1. Acesse [vercel.com](https://vercel.com) e login na sua conta
2. Clique em "Add New Project"
3. Selecione o repositório `iury-art-site` do GitHub
4. O Vercel detectará automaticamente os arquivos HTML estáticos
5. Clique em "Deploy" para publicar

**Atualização automática:** Commitar novos arquivos no branch `master` acionará build automático no Vercel.

### GitHub Pages (Alternativa)

1. Vá em Settings > Pages
2. Selecione a branch `main` e pasta `/` (root)
3. Configure o domínio customizado `iury.art`
