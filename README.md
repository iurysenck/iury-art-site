# iury.art

Site pessoal e portfolio de Iury Senck - Fotógrafo & Produtor de Conteúdo Visual.

## 🌐 Acesse

**[iury.art](https://iury.art)**

## ✨ Features

- Design moderno estilo Awwwards
- Cursor personalizado interativo
- Animações suaves on scroll
- Efeito parallax no hero
- Grid de portfolio responsivo
- Formulário de contato funcional
- Totalmente responsivo

## 🛠️ Stack

- HTML5 semântico
- CSS3 com variáveis customizadas
- JavaScript Vanilla
- [Lucide Icons](https://lucide.dev)
- Google Fonts (Space Grotesk, Syne)

## 📁 Estrutura

```
site/
├── index.html          # Página principal
├── robots.txt          # Config para crawlers
├── sitemap.xml         # Sitemap para SEO
└── imgs/
    ├── about-iury.jpg  # Foto pessoal
    └── portfolio/      # Imagens do portfolio
```

## 🚀 Deploy

O site está configurado para deploy via GitHub Pages ou qualquer hospedagem estática.

### GitHub Pages

1. Vá em Settings > Pages
2. Selecione a branch `main` e pasta `/` (root)
3. Configure o domínio customizado `iury.art`
