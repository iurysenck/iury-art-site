## 🎨 O Projeto

Este repositório contém o código fonte do site **iury.art**, um portfólio digital premium desenvolvido para apresentar suas produções artísticas e comerciais em uma experiência imersiva e de alta performance.

### ✨ Diferenciais do Site

- **Estética Awwwards & Premium:** Design em Dark Mode com efeitos de *glassmorphism*, gradientes harmônicos e transições fluidas.
- **Canvas Interativo 3D (Three.js):** Experiência visual imersiva com efeitos de partículas 3D no background que reagem ao scroll e interação do usuário.
- **Tipografia Expressiva:** Contraste marcante usando a fonte **Syne** para títulos de impacto e **Space Grotesk** para informações e dados técnicos.
- **Micro-interações:** Cursor personalizado reativo, hover dinâmico nos cards de portfólio e easter eggs (como o ícone interativo de DOOM).
- **SEO & Performance:** Totalmente estruturado para SEO (sitemap e robôs integrados) e com carregamento altamente otimizado.

---

## 🛠️ Stack & Tecnologias

- **Visual / Interatividade:** JavaScript Vanilla, [Three.js](https://threejs.org/) para renderização 3D, HTML5 Semântico e CSS3 puro (com variáveis dinâmicas).
- **Fontes:** Google Fonts (Space Grotesk, Syne).
- **Ícones:** [Lucide Icons](https://lucide.dev).
- **SEO:** Sitemap XML estruturado e robots.txt otimizado.

## 📁 Estrutura do Repositório

```text
site/
├── index.html          # Interface principal e lógica do site (traduções, interações, 3D)
├── doomicon.js         # Lógica do ícone interativo retro no rodapé
├── DESIGN.md           # Sistema de design (visual tokens, cores, tipografia)
├── stitch/             # Configurações e assets para importação no Google Stitch Canvas
├── robots.txt          # Configurações para indexadores de busca (crawlers)
├── sitemap.xml         # Sitemap para otimização SEO do domínio principal
└── imgs/               # Otimizado com imagens de projetos e retratos
```
